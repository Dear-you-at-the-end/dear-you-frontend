# 💌 몰입의 끝에서 너에게

> **"눈을 뜨니 몰입캠프의 마지막 날이었다."**
> 안개처럼 사라진 기억 속, 손에 남은 건 휴대폰뿐.
> 오늘 안에 2분반 모두에게 편지를 배달해야 한다. 그런데... 전달해야 할 편지가 어디에도 없다?!

## 🍀 핵심 컨셉 (Core Concept)

* 🎭 **스토리** : 잃어버린 편지를 찾아 참가자들에게 전달하는 감성 스토리
* 🗺️ **탐험** : 실제 KAIST 캠퍼스를 모티브로 제작한 맵 탐험
* 🎮 **미니게임** : 장소별 특색 있는 미니게임 진행
* 💌 **편지 시스템** : 참가자 간 진심 어린 메시지를 주고받는 기능
